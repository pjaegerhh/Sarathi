# ✅ Updated Profile Selection to Save user_type to Database

## What Changed

### ProfileSelectionPage.tsx

**Added:**
1. Import `useAuth`, `supabase`, and `toast`
2. Get `user` from auth context
3. Added `loading` state
4. Made `handleNext` async

**When user clicks "Next":**
```typescript
1. Updates sarathi_user table:
   UPDATE sarathi_user 
   SET user_type = 'amputee' / 'caregiver' / 'volunteer' / 'healthcare'
   WHERE uuid = user.id

2. Shows loading state on button ("Saving...")

3. On success: Navigates to profile-complete page

4. On error: Shows toast error and stays on page
```

## Complete Registration Flow

### Step 1: Register (RegistrationPage)
- Creates auth user
- Waits for trigger to create sarathi_user row
- If trigger fails, manually creates row with ALL data:
  - uuid, email, user_type: 'amputee' (default)
  - name, first_name, telephone, date_of_birth
- If trigger succeeds, updates the row with additional data

**Database after Step 1:**
```sql
uuid: [generated]
email: user@example.com
name: "John Doe"
first_name: "John"
telephone: "1234567890"
date_of_birth: "1990-01-01"
user_type: "amputee" (default)
```

### Step 2: Email Verification
- User clicks link in email
- Supabase verifies email
- User is automatically logged in
- Redirected to profile-verified page

### Step 3: Profile Selection (ProfileSelectionPage)
- User selects profile type:
  - 🦿 Amputee
  - 👨‍⚕️ Caregiver  
  - 🤝 Volunteer
  - ⚕️ Healthcare Professional
- Clicks "Next"
- Updates database: `user_type = selected_value`

**Database after Step 3:**
```sql
uuid: [same]
email: user@example.com
name: "John Doe"
first_name: "John"
telephone: "1234567890"
date_of_birth: "1990-01-01"
user_type: "caregiver" ← UPDATED!
```

### Step 4: Profile Complete
- Shows success message
- Clicks "Explore Sarathi"
- Goes to homepage as logged-in user

## What Gets Saved

| Field | When Saved | Value |
|-------|-----------|-------|
| uuid | Registration (auto) | Generated by Supabase |
| email | Registration (trigger) | From form |
| name | Registration (UPDATE/INSERT) | "FirstName LastName" |
| first_name | Registration (UPDATE/INSERT) | From form |
| telephone | Registration (UPDATE/INSERT) | From form |
| date_of_birth | Registration (UPDATE/INSERT) | From form |
| user_type | Registration (trigger) | 'amputee' (default) |
| user_type | Profile Selection (UPDATE) | Selected by user ← NEW! |
| created_at | Registration (auto) | Current timestamp |
| updated_at | Registration (auto) | Current timestamp |
